# Privacy Policy — Bulb-Personal-Sync

Last updated: 2026-09-29

This application is for the personal use of its developer only.

- It reads my own Oura Ring data through the Oura API with my authorization.
- Data is stored only on my local device and is not shared with, sold to, or disclosed to any third party.
- No data from other users is collected.
- Access can be revoked at any time from Oura account settings, and locally stored data can be deleted at any time.
